### MODEL 1: CROP RECOMMENDATION CLASSIFIER (SHADOW EXECUTION)
- Task: Regional crop classification based on historical agricultural census patterns
- Artifact Location: models/crop_recommendation/model.joblib
- Metadata Location: models/crop_recommendation/metadata.json
- Training Dataset: data/processed/clean_apy_yield.csv (DESAgri Census 1997-2015)
- Predictor Features:
    1. State_Name (Categorical - One-Hot Encoded)
    2. District_Name (Categorical - One-Hot Encoded)
    3. Season (Categorical - One-Hot Encoded)
    4. Crop_Year (Numeric - Standard Scaled)
    5. Area (Numeric - Cultivated Area in Hectares)
- Target Classes (20 Major Crops):
    Bajra, Banana, Cotton(lint), Dry chillies, Gram, Groundnut, Guar seed, Jowar,
    Jute, Maize, Moong(Green Gram), Onion, Potato, Rapeseed & Mustard, Rice,
    Sesamum, Soyabean, Sugarcane, Urad, Wheat.
- Evaluation Metrics:
    * Test Accuracy         : 60.33% (0.6033)
    * Weighted F1-Score     : 0.4828
    * Macro Precision       : 0.8124
    * Macro Recall          : 0.8241
- Model Comparison Results:
    * DummyClassifier       : Accuracy = 37.31% | Weighted F1 = 0.2027
    * LogisticRegression    : Accuracy = 80.89% | Weighted F1 = 0.8055
    * DecisionTreeClassifier: Accuracy = 70.54% | Weighted F1 = 0.6699
    * RandomForestClassifier: Accuracy = 60.33% | Weighted F1 = 0.4828
- Runtime Policy:
    Executes internally in shadow mode and logs predictions to `reports/internal/crop_ml_internal.log`.
    Farmer-facing recommendations are derived from empirical DESAgri historical acreage rankings 
    verified by the State Crop Catalog to prevent ungrounded machine learning hallucinations.
- Visual Diagnostics Generated (300 DPI):
    * reports/metrics/crop_ml/class_prediction_analysis.png
    * reports/metrics/crop_ml/confusion_matrix.png
    * reports/metrics/crop_ml/feature_importance.png

### MODEL 2: SOIL HEALTH FERTILITY CLASSIFIER (ZERO TARGET LEAKAGE)
- Task: Laboratory soil chemical parameter diagnosis and overall fertility classification
- Artifact Location: models/soil_health/model.joblib
- Metadata Location: models/soil_health/metadata.json
- Training Dataset: data/processed/clean_soil_fertility.csv (Soil Health Card lab tests)
- Total Samples: 1,070 lab records (856 Train / 214 Test - 80/20 Stratified Split)
- Predictor Features (7 Non-Target Chemical Parameters):
    1. pH (Soil Reaction - continuous)
    2. EC (Electrical Conductivity in dS/m - continuous)
    3. S (Available Sulfur in mg/kg - continuous)
    4. Zn (Available Zinc in mg/kg - continuous)
    5. Fe (Available Iron in mg/kg - continuous)
    6. Mn (Available Manganese in mg/kg - continuous)
    7. Cu (Available Copper in mg/kg - continuous)
- Target Leakage Safeguard:
    Primary macronutrients (Organic Carbon, Phosphorus, Potassium) were strictly excluded from model 
    inputs because the target fertility class is derived from NPK thresholds.
- Target Classes: Low, Medium, High
- Evaluation Metrics:
    * Test Accuracy         : 78.04% (0.7804)
    * Weighted F1-Score     : 0.7715
    * Weighted Precision    : 0.7780
